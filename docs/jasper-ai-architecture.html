📋 2. 系統分層與元件職責對照表 (System Layer & Component Specifications)

架構分層 技術 Stack 核心職責說明
1. 使用者介面層 (UI Layer) Web Browser, Mobile Browser RM 專屬客製化 Wizard 介面、互動式持倉調整、響應式儀表板展演
2. Web 應用與 BFF 層 (apps/web) Next.js 15, React 19, Tailwind CSS, Recharts RM Wizard 介面、雙軌收益與風險雷達圖、AI 雙模型路由 (Kimi/Gemini)、validateNarrative() 零幻覺驗證、/quant-api Proxy
3. 量化引擎 API 層 (apps/api) FastAPI, Uvicorn, Asyncio 非同步 Backtest 任務調度、Job 狀態輪詢與排程、Champion 組合快取與 SQLite 持久化管理
4. 量化核心演算法 (Quant Engine) Optuna, pandas, numpy, scipy 多目標優化搜尋、幾何約束權重解算、Factor Scoring、70/30 OOS 樣本外交叉驗證、雙軌重放回測
5. AI 雙模型層 (AI Models & Guardrails) Moonshot Kimi K3 + Google Gemini 3.6 Flash Kimi K3 負責高價值推理與提案敘事撰寫；Gemini 3.6 Flash 負責結構化 JSON 指令萃取與低延遲常規呼叫；結合 validateNarrative() 事實核查機制
6. 資料與快取持久層 (Persistence Layer) Parquet, SQLite, JSON, LocalStorage 歷史價格快取 (.parquet)、冠軍模型庫 (champions.db)、靜態 ETF Universe 與 Client Profile JSON
7. 外部服務 (External Services) yfinance API, SMTP 自動擷取市場最新行情數據、發送 Email 提案通知書（選用）
💡 核心設計金律 (Core Architecture Principle)：
「數字與風險分析由 Python 量化引擎精確計算，LLM 僅負責結構化需求萃取與無幻覺敘事生成。」所有投資組合回測指標（報酬率、夏普比率、最大回撤、權重）皆由 Python 量化引擎產生，LLM 僅能調用經審查之 Fact Table 進行文字敘事，杜絕理財提案中的 AI 數字幻覺。
